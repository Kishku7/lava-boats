# Lava Boats - NeoForge 26.2 (Minecraft 26.2 (pre-release))

Builds the **NeoForge** jar for **Minecraft 26.2 (pre-release)**. Client + server mod.

- Loader: NeoForge
- Minecraft: 26.2 (pre-release)
- Java: 25
- Toolchain: ModDevGradle (MDG), built vs a NeoForge 26.2 alpha (standalone - no Architectury, no shared `Common/`)

## Build

```
./gradlew build      # Windows: .\gradlew.bat build
```

Output: `build/libs/lava-boats-*.jar`

Part of the [`26.2` branch](https://github.com/Kishku7/lava-boats/tree/26.2). [Modrinth](https://modrinth.com/mod/lava-boats) - [Releases](https://github.com/Kishku7/lava-boats/releases).
