# Lava Boats - NeoForge 26.1.2 (Minecraft 26.1.2)

Builds the **NeoForge** jar for **Minecraft 26.1.2**. Client + server mod.

- Loader: NeoForge
- Minecraft: 26.1.2
- Java: 25
- Toolchain: ModDevGradle (MDG), NeoForge 26.1.2.30-beta (standalone - no Architectury, no shared `Common/`)

## Build

```
./gradlew build      # Windows: .\gradlew.bat build
```

Output: `build/libs/lava-boats-*.jar`

Part of the [`26.1` branch](https://github.com/Kishku7/lava-boats/tree/26.1). [Modrinth](https://modrinth.com/mod/lava-boats) - [Releases](https://github.com/Kishku7/lava-boats/releases).
