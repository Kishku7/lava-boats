# Lava Boats - NeoForge (Minecraft 26.2 (pre-release))

**NeoForge** loader builds of Lava Boats for the Minecraft 26.2 (pre-release) line. Client + server mod.
Standalone - no Architectury, no shared `Common/`.

## Builds

| Version | Minecraft | Java | Toolchain |
| --- | --- | --- | --- |
| [`26.2/`](26.2) | 26.2 (pre-release) | 25 | ModDevGradle (MDG), built vs a NeoForge 26.2 alpha |

## Build

```
cd <version>
./gradlew build      # Windows: .\gradlew.bat build
```

Output: `build/libs/lava-boats-*.jar`. Part of the [`26.2` branch](https://github.com/Kishku7/lava-boats/tree/26.2).
