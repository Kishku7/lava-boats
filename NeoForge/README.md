# Lava Boats - NeoForge (Minecraft 26.1.2)

**NeoForge** loader builds of Lava Boats for the Minecraft 26.1.2 line. Client + server mod.
Standalone - no Architectury, no shared `Common/`.

## Builds

| Version | Minecraft | Java | Toolchain |
| --- | --- | --- | --- |
| [`26.1.2/`](26.1.2) | 26.1.2 | 25 | ModDevGradle (MDG), NeoForge 26.1.2.30-beta |

## Build

```
cd <version>
./gradlew build      # Windows: .\gradlew.bat build
```

Output: `build/libs/lava-boats-*.jar`. Part of the [`26.1` branch](https://github.com/Kishku7/lava-boats/tree/26.1).
